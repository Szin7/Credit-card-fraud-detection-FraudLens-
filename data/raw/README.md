# Raw data

## What's here

`creditcard_sample.csv` is a **synthetic** dataset generated by
[`scripts/generate_sample_data.py`](../../scripts/generate_sample_data.py)
for local development and dashboard demos. It is **not** the real
credit-card fraud dataset — it exists only so the pipeline and dashboard
work out of the box without you having to source real data first.

The schema matches the real dataset (`Time`, `V1`–`V28`, `Amount`, `Class`)
so downstream code doesn't care which one it's reading, but every value is
fabricated:

- `V1`–`V28` are independent Gaussian draws. A handful of them get an
  arbitrary shift for fraud rows purely so a classifier has something to
  learn — this has no relationship to what those components mean in the
  real (PCA-anonymized) dataset, and this codebase never assigns them
  invented real-world meaning.
- `Amount` is lognormal, shifted slightly for fraud rows.
- `Time` spans 48 hours, matching the real dataset's span.
- 25 exact duplicate rows are injected on purpose so validation's dedup
  logic has something real to catch.

**Any metrics or dashboard numbers produced from this file describe the
synthetic sample, not real-world fraud detection performance.** They're
labeled as such throughout `docs/`.

## Using the real dataset

1. Download the "Credit Card Fraud Detection" dataset (`creditcard.csv`)
   from Kaggle: <https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud>.
2. Place the file at `data/raw/creditcard.csv`.
3. Set `RAW_DATA_FILENAME=creditcard.csv` in `.env`.
4. Re-run the pipeline (`make pipeline`, or the individual `make ingest` /
   `make validate` / `make train` / `make predict` steps).

`creditcard.csv` is gitignored — it has its own redistribution terms on
Kaggle, so it's never committed to this repository.
